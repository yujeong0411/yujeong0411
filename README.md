## 프로젝트

### NurseScheduler — 응급실 간호사 근무표 자동 생성 시스템
간호사 시절 직접 겪은 근무표 작성의 어려움을 해결하기 위한 개인 프로젝트.
OR-Tools CP-SAT 솔버를 활용해 21종 근무·휴무 코드, 20여 개 하드 제약,
6개 소프트 목적함수를 설계했고, 간호사 신청 화면과 관리자 대시보드,
엑셀 내보내기까지 풀스택으로 구현했습니다.
- Tech: Python, FastAPI, OR-Tools, React, Supabase
- Repo: (링크)

### Dr.Navi — RAG 기반 진료과 추천 서비스
증상에 맞는 진료과를 찾기 어려운 사용자를 돕는 의료 챗봇.
서울아산병원 질병정보 1,577건을 직접 수집·구조화하고 LangChain 기반
RAG 파이프라인을 설계했습니다. Context Precision 96.5% 달성,
전문의 2인으로부터 임상 활용 가능 평가를 받았습니다.
- Tech: Python, LangChain, Pinecone, OpenAI
- Repo: https://github.com/yujeong0411/Dr.Navi

### Safe Connect — WebRTC 기반 응급의료 협업 플랫폼
신고자–상황실–구급대–응급실 사이에서 정보가 끊기는 문제를 해결하기 위한
실시간 영상 협업 MVP. 5개 사용자 역할별 화면을 React/TypeScript로 구현했습니다.
- Tech: React, TypeScript, WebRTC
- Repo: https://github.com/yujeong0411/Safe-Connect

### POSS — 생산계획 최적화 시스템 (삼성전자 연계)
복잡한 생산계획 수립 시간을 줄이기 위한 GUI 기반 분석 도구.
Pandas·NumPy로 데이터를 처리하고 PyQt5로 인터페이스를 구현했습니다.
계획 수립 시간 75% 단축.
- Tech: Python, PyQt5, Pandas
- Repo: https://github.com/yujeong0411/POSS
